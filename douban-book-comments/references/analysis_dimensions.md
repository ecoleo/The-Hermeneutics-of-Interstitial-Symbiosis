# 豆瓣短评的可拓展分析维度

基础脚本已覆盖评分分布、时间趋势、关键词、高低分特征词。以下维度需在此基础上二次开发，
按「成本 / 收益」排序，供数字人文与文学接受研究参考。

## 一、低投入，直接可用

### 1. 接受史分期与话语漂移
`yearly_keywords.csv` 已给出分时段关键词。进一步可做：
- **时段划分不按自然年，而按出版/影视/教材事件**（如某版本再版、某改编剧播出），
  用事件前后对比替代等距分期，解释力更强。
- **关键词生命周期曲线**：某词（如「油滑」）在时段的出现率折线，识别话语兴衰。

### 2. 评价分歧的语义定位
`keywords_by_rating.csv` 的高低分特征词对比，可直接读成「争议焦点」。
若样本中低分稀缺（热门排序下极常见，本次《故事新编》1–2★ 占比即 0%），
应改从 `sort=time` 补采或直接承认该维度不可分析。

### 3. 高赞话语的体裁分析
`top_comments.csv` 的高赞短评往往不是文学批评，而是**梗、段子、情绪宣言**。
建议人工标注 30–50 条，归纳话语类型（考据型 / 感悟型 / 玩梗型 / 政治隐喻型），
再统计各类型占比——这比词频更能说明"大众读者如何谈论经典"。

## 二、中等投入，需额外依赖

### 4. 主题建模（BERTopic / LDA）
短评文本短、噪声大，直接 BERTopic 效果一般。建议：
- 先按星级或时段分组，组内聚合后再建模；
- 或用 `sentence-transformers` 的中文模型（`paraphrase-multilingual-MiniLM-L12-v2`
  或 `text2vec-base-chinese`）生成句向量再聚类；
- 主题数宁少勿多（k=5–10），短文本上过多主题只会碎片化。

### 5. 情感分析的正确用法
- **豆瓣星级本身就是高质量的情感标注**，任何模型结果都应先与星级做一致性检验
  （交叉表 + Cohen's kappa）。一致性低于 0.6 时，说明模型不适用于该语料，应弃用。
- SnowNLP 基于电商评论训练，对文学性短评（反讽、用典、"油滑"式褒贬）误判严重。
  若必须使用，须在方法论中声明其为**启发式辅助指标**，结论不得单独依赖它。
- 更稳妥：用星级做主指标，用情感模型只做**趋势对照**，并报告两者背离的样本。

### 6. 与原作/参照文本的语义相似度
若要回答"读者评论在什么意义上接近或偏离原作话语"（对应 Ch4 生成实验的对照思路）：
- 用 BERTScore 计算短评与原作语段的相似度，需固定：模型层、切分粒度、参照集。
- **方法口径必须写死**：层号、切分长度、单参照 vs 多参照取最优，
  三者任一变化都会显著改变分数，跨研究不可比。

## 三、高投入，方法论上更值得

### 7. 多版本对照
同一作品的不同版本（如《故事新编》#2046909 / #26285194 / #34858983）
在豆瓣是独立条目，短评话语差异可反映**版本、封面、导读、出版社**对接受的塑造。
做对照时须控制：样本量、采集深度、时间窗三者一致。

### 8. 跨文本比较
把目标书与同作者其他作品、或同时代同类作品的评分分布放在一起，
才能判断"这本书的评分高不高"——单书绝对分数几乎没有解释力。

## 数据纪律建议

1. **原始 JSONL 永不改写**，所有衍生结果写入新文件，保证可复现。
2. **保留原始 HTML**（`--keep-html`），页面结构变更时可回溯核验字段抽取是否正确。
3. **任何统计数字进入正文前，必须能在 CSV 中被逐行复算**。
4. **覆盖率与方法局限写在结论旁边**，不要只藏在脚注里。
5. 引用短评原文时匿名化用户名，或仅引用不标注用户。
