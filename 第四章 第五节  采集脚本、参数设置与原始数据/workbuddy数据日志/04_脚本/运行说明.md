# 脚本运行说明

> 所有路径以本交付包同级工作区根目录为基准；脚本内路径均自动定位（脚本须位于 `scripts/` 或保持相对结构）。
> 两套 Python：采集/统计用 3.13.12 纯标准库；图表与 docx 用含 matplotlib/python-docx 的 venv。

## 一、采集脚本

| 脚本 | 用途 | 运行方式 | 关键参数 |
|---|---|---|---|
| `bili_fetch.py` | B站双轨采样 | `python bili_fetch.py` | 关键词/排序/页数在文件头部常量；无需登录 |
| `douban_fetch.py` | 豆瓣短评采集 | `python douban_fetch.py --id 2046909 --status P --sort hot --max-pages 25 --delay 10-15 --cookie-file <cookie路径> --out <输出目录>` | 触发"禁止访问"风控页即自动停止 |
| `douban_analyze.py` | 豆瓣统计 | `python douban_analyze.py --input <merged.jsonl> --out <目录> --sentiment off` | sentiment 按数据纪律置 off |
| `weread_collect.py` | 微信读书四层采集 | `WEREAD_API_KEY=<key> python weread_collect.py` | key 仅从环境变量读取；采样规则为脚本内预登记常量 |
| `douyin_probe.py` | 抖音可行性探测 | `python douyin_probe.py`（cookie 路径硬编码于文件头，需自备） | 仅探测，无量产输出 |

## 三、复跑顺序

1. `bili_fetch.py` → `bili_analyze.py`
2. `douban_fetch.py`（两轮）→ 合并去重（一行脚本，见复现说明 3.2）→ `douban_analyze.py`
3. `weread_collect.py` → `weread_code.py`
4. `charts.py`
5. `revise_docx.py`
6. `lexicon_sensitivity.py`（稳健性检验，可选；B站部分口径与 `bili_analyze.py` 严格对齐——标签精确匹配 + (bvid,关键词) 去重，仅变词表）

## 四、注意事项

- `weread_collect.py` 绝不在命令行参数或文件中接收 key，仅认 `WEREAD_API_KEY` 环境变量
- `douban_fetch.py` 的 cookie 若含非 ASCII 字符（如中文昵称），脚本已自动百分号编码
- 所有脚本请求间隔 ≥1s，请勿调小
