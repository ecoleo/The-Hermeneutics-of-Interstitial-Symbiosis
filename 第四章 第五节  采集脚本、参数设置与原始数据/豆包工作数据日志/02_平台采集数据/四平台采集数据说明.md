## 1. B站（子目录 `B站/`）

### 1.1 样本范围与采集方式
- 检索关键词：`故事新编 鲁迅`、`故事新编`、`鲁迅`（由窄到宽，便于观察检索意图明确度的影响）。
- 排序条件：每个关键词分别取 `totalrank`（综合排序，算法默认入口）与 `pubdate`（最新排序，近似时间流）各前 **8 页**（每页约 20 条）。
- 去重规则：以 `bvid × 关键词` 为键；同一 bvid 在不同关键词下保留（因为它在不同检索词下的"可见性"本身是分析对象），同一关键词-排序内重复命中只计一次。
- 采集量：故事新编 鲁迅 230（综合 140/最新 90）、故事新编 279（143/136）、鲁迅 288（132/156），合计 **797**。
- **宽词召回噪声的如实披露**：宽关键词"故事新编""鲁迅"会召回少量同名但与鲁迅小说无关的结果（如"多萝西娅·兰格摄影故事新编""新编三十六计全书""小学四年级〈习作：故事新编〉公开课"等），这是检索词本身的歧义所致，属真实可见结果、未作人工删除。论文的**主结论以窄词"故事新编 鲁迅"为准**（该词无此类歧义），宽词仅用于观察排序机制与检索意图宽度的影响；这一选择也解释了何以同时报告三关键词而非只报合并值。
- 途径：调用 B站公开搜索接口，WBI 签名参数由 Python 标准库（urllib + hashlib + 时间戳/混合密钥）自行实现，未使用第三方爬虫框架；请求间隔约 1.5 秒，三关键词总耗时约 164 秒。

### 1.2 字段定义（`bili_<关键词>_anon.jsonl`，每行一个视频）
| 字段 | 含义 |
|---|---|
| bvid / aid | 视频 BV 号 / AV 号（公开主键） |
| title | 视频标题 |
| author | UP 主昵称，**交付版已匿名化为 UP_001…**（本地原始版保留昵称，未交付） |
| ~~mid~~ | UP 主数字 UID，**交付版已移除以避免可定位个人** |
| play / danmaku / like / favorites | 播放量 / 弹幕数 / 点赞 / 收藏（采集时点值，字符串原样保留） |
| pubdate | 发布时间，Unix 秒 |
| duration | 时长（`分:秒`） |
| tid / tid_name | 分区 ID / 分区名 |
| tags | 完整标签集（列表，标签可多重命中，故各类别占比之和可大于 100%） |
| _order | `totalrank`=综合排序，`pubdate`=最新排序 |
| _keyword | 命中的检索关键词 |
| _fetched_at | 采集时间戳 |

### 1.3 衍生统计文件
- `bili_category_stats.csv`：四类预登记标签词典（文学品质类/知识教育类/有声说书类/幽默解构类）在"关键词×排序"下的样本量、命中数、占比、Wilson 95% 置信区间。
- `bili_order_tests.csv`：同一关键词两种排序占比差异的两比例 z 检验（z、p、判读）。
- `bili_tags_top.csv`：全样本标签词频（用于图 2）。
- `bili_<关键词>_meta.json`：每个关键词的采集参数、分排序计数、耗时与方法学备注。

### 1.4 类别词典（预登记，分析前固定，未在看到结果后调整）
- 文学品质类：文学/小说/经典/名著/人文/语文/现代文学/作家/作品/原文/原著 等；
- 知识教育类：知识/科普/讲解/解读/课程/教学/教授/历史/学习/考试/中考/高考 等；
- 有声说书类：有声书/说书/朗读/演播/听书/广播剧/评书 等；
- 幽默解构类：搞笑/吐槽/毒舌/讽刺/幽默/鬼畜/整活/玩梗/沙雕 等。
> 一条视频可同时命中多个类别；词典全文见 `05_分析脚本/bili_analyze.py`。

## 2. 豆瓣（子目录 `豆瓣/`）

### 2.1 样本范围与采集方式
- 对象：《故事新编》图书页 subject id **2046909**（人民文学出版社通行版本条目）。
- 排序：`new_score`（热门/最有用排序）与 `time`（最新排序）各取前 5 页、每页约 20 条，各 100，合计 **200 条**。
- 页面声明短评总量 **8790 条**，本样本覆盖率 **2.28%**。
- 访问限制说明：**匿名（未登录）状态下按时间排序请求会被平台返回 403**，故本采集使用研究者本人登录态 Cookie 通过访问限制（Cookie 不写入任何交付文件）；请求间隔约 18 秒以遵守约 200 请求/小时/IP 的限流，未触发封禁。
- **重要替代声明（论文与复现说明同步声明）**：该书页"常用标签云"由前端 JavaScript 动态加载，静态请求与登录态请求均无法稳定获得标签列表，故**以 200 条短评正文的分词词频作为读者标注的替代观测**，结论口径为"短评正文话语"而非"标签云"。
- 因公开材料不提供标签/短评的完整历史时间序列，**本研究不计算、也不主张任何"增速/增长率"**。

### 2.2 字段定义（`comments_2046909_anon.jsonl`，每行一条短评）
| 字段 | 含义 |
|---|---|
| cid | 短评公开 ID（主键） |
| user | 用户昵称，**交付版匿名化为 读者_001…** |
| rating | 星级 1—5（字符串；少量短评无评分） |
| rating_title | 星级文字（力荐/推荐/还行/较差/很差） |
| votes | "有用"投票数 |
| time | 短评发布时间（`YYYY-MM-DD HH:MM:SS`） |
| location | 作者标注地域（多为空，非个人定位信息） |
| text | 短评正文 |
| _sort | `new_score`=热门，`time`=最新 |
| _fetched_at | 采集时间 |

### 2.3 衍生统计文件
- `stats.json`：样本量、评分均值/中位数/标准差、各星占比、短评长度、"有用"均值/最大值、年份跨度、分词器说明与方法学 caveat。
- `rating_distribution.csv` / `rating_title_distribution.csv`：星级分布（图 3 左）。
- `keywords_top.csv`：jieba 分词 + TF-IDF 后的高频实词表（图 3 右），列＝关键词/词频/TF-IDF 权重（UTF-8-BOM）。
- `keywords_by_rating.csv`：分星级词频；`length_distribution.csv`：短评长度分布；`top_comments.csv`：高"有用"短评；`yearly_trend.csv`、`yearly_keywords.csv`：按年分布（**仅描述样本年份构成，不外推为平台增速**）。

### 2.4 消遣词核验口径（两处口径并存，论文已注明）
- **jieba 分词词频**（与图 3、keywords_top.csv 一致）：解构 11、戏谑 9、荒诞 9、讽刺 8。
- **全文子串计数**（更保守，防止分词切散；见 `汇总统计/summary_stats.json` 的 `buzzword_substr_count` / `critique_substr_count`）：爽文/嘴替/互联网嘴替/魔改/整活/玩梗＝0；毒舌 1、吐槽 1（经人工核读，两处均为传统文学批评语境："不愧是毒舌之王"评文笔、"《理水》吐槽顾颉刚"作真人影射考据）；解构 11、戏谑 9、荒诞 10、讽刺 8、反讽 3、幽默 8。

## 3. 抖音（子目录 `抖音/`）

### 3.1 样本范围与采集方式（受阻—替代路径的完整记录）
- **已尝试但确认不可行的路径（如实记录）**：以 Python requests/urllib 直接请求抖音搜索接口，因缺少 `a_bogus` 等前端签名参数，返回空 `data` 或验证码中间页（约 5.9 KB 的验证页），稳定不可行；八爪鱼采集器官方亦已下架抖音采集模板。
- **最终可行路径**：改用平台内置受控浏览器（Browser Use 自动化）打开抖音网页版搜索：
  1. 首次打开搜索页弹出登录框，**由研究者本人扫码登录**（人工接管一次）；
  2. 检索 `鲁迅说`（URL 编码 `%E9%B2%81%E8%BF%85%E8%AF%B4`），通过 `window.scrollBy(0,1500)` 逐轮滚动、每轮停留 2.0 秒，共 14 轮，按卡片 innerText 去重，得 **147 条**，继续滚动不再新增；
  3. 切换 `故事新编 鲁迅` 时触发图形拖拽验证码，**再次由研究者本人手动通过**（人工接管第二次），重采得 **18 条**（该长尾词结果总量即约 18 条，滚动后稳定不增）。
- 抽取对象：搜索结果卡片 `div.search-result-card` 的 innerText，格式为"形式或时长 | 点赞 | 文案（含 #话题） | @作者 | · 时间"；以"相关搜索"开头的推荐卡片已过滤。
- **方法学限度**：单账号、单时点、综合排序下的**可见性快照，非概率抽样**；不同账号/时点的个性化排序可能不同，论文据此只作"可见性结构描述"，不作总体推断。

### 3.2 原始文件
- `douyin_鲁迅说_raw_anon.jsonl`（147 行）、`douyin_故事新编鲁迅_raw_anon.jsonl`（18 行）：每行 `{query, raw}`，`raw` 为卡片原始 innerText，**交付版已将 `@昵称` 正则替换为 `@匿名创作者`**。

### 3.3 解析与编码文件 `douyin_parsed_anon.csv`（165 行，UTF-8-BOM）
| 列 | 含义 |
|---|---|
| query | 检索词（鲁迅说 / 故事新编 鲁迅） |
| 载体形式 | 图文 / 视频（由首段"时长 or 图文"判定） |
| 时长秒 | 视频时长（图文为空） |
| 点赞数 | 数值化后的点赞量（"万/亿"已换算，如 1.5万→15000） |
| 内容形式主类 | 六类编码结果（见 3.4） |
| 标题 | 卡片文案 |
| 话题标签 | 正则抽取的 `#话题#` 列表 |
| 作者 | **交付版匿名化为 创作者_001…** |

| 编码命中 | 命中的规则标记，便于复核归类理由 |

### 3.4 内容形式编码本（两轮开放编码校准后锁定，分析前固定）
- 类别（互斥）：**剧情演绎类 / 知识讲解类 / 仿写玩梗类 / 名句呈现类 / 共鸣纪念类**，另设**无关混入**（与鲁迅/作品无关）与**其他**（无法判定）。
- 优先级（一条命中多类时）：剧情演绎 > 知识讲解 > 仿写玩梗 > 名句呈现 > 共鸣纪念 > 相关性判定 > 其他。
- 识别要点：QUOTE_MARKERS/引号识别直接引用的原句（名句）；RELEVANCE_MARKERS 判定无关混入（仿写玩梗类豁免相关性覆盖）；图文若无明确特征，推定为名句呈现。
- 校准过程：第一轮开放编码后逐条复核"其他/混入"，补充规则后第二轮重编码，最终"其他"仅 3.4%，规则随即锁定、不再据结果回调。完整规则与关键词表见 `05_分析脚本/douyin_parse.py`。

## 4. 微信读书（子目录 `微信读书/`）

### 4.1 样本范围与采集方式
- 对象：人民文学出版社版《故事新编》，bookId **40509933**（主版本）；另一电子书版 bookId 3300227306 仅 3 条划线、1 条点评，不具分析价值，已在主文件中保留但不纳入统计。
- 途径：经微信读书**官方 Agent API Gateway**（`https://i.weread.qq.com/api/agent/gateway`，weread-skills v1.0.4）调用，非网页爬取：
  - `/book/bestbookmarks`（chapterUid=0，全书）：服务端**固定按热度返回前 20 条**热门划线，回包声明全书划线总量 **449 条**，不支持分页；
  - `/review/list`（reviewListType=0 全部）：返回前 **20 条**公开点评，回包声明点评总量 **547 条**。
- 鉴权使用研究者本人 API Key（Bearer），**Key 仅经环境变量临时传入，不落盘、不出现在任何交付文件中**；建议使用后轮换。
- 匿名化：回包中 userVid、name、avatar 等身份字段已**递归移除**后再保存。

### 4.2 文件结构 `weread_故事新编_采集_2026-09-12.json`
```
{ "<bookId>": {
    "bestbookmarks": {"totalCount": 全书划线总量, "n": 返回条数, "items": [ {chapterUid, range, markText(划线原文), totalCount(划线人数)} … ]},
    "reviews":     {"reviewsCnt": 点评总量, "n": 返回条数, "items": [ {star(100五星/80四星/60三星…), content, createTime, …(已匿名)} … ]}
} }
```
### 4.3 篇目归属
热门划线的 chapterUid 到篇目的映射，依据划线文本内证建立：4=序言；5—7=补天；8、10=奔月；12、13=理水；18=采薇；20、22=铸剑；30、31=非攻（映射表见 `05_分析脚本/analysis_all.py` 的 WEREAD_CHAPTER）。Top20 篇目分布：补天 6、理水 5、铸剑 3、奔月 2、非攻 2、序言 1、采薇 1。

## 6. 数据使用与复核约定
1. 论文正文每个百分比、计数、检验量都可回溯到本目录原始文件与 `汇总统计/summary_stats.json`；复核入口见 `01_复现说明` 的一致性核对表。
2. 所有样本均为**特定时点、特定检索条件下的可见性快照**，不是平台总体的随机抽样；凡涉及"算法导致"的表述，论文一律降级为"前端可见结果与算法排序机制相一致"的观测性表述。
3. 交付数据不含任何凭据与可定位个人的标识；如需在本机复现采集，Cookie/API Key 需使用者自行提供并经环境变量注入，脚本不会把它们写入结果文件。
