# 数据附录文件包 README（定稿版）

> 本文件夹为《故事新编》数字人文分析（定稿版）的数据附录文件包，与正文"第三方可复核"承诺配套。全部文件由本研究实际执行的数据管线原位生成，未做任何事后修饰。生成日期：2026-09-05。

|---|---|

## 三条口径纪律（与正文一致）

1. **校准值为唯一呈现口径**：本文件包及正文中一切《铸剑》情感数值均为"人工标注效价＋语境情感词典"校准值；SnowNLP 裸输出不进入任何呈现文件，仅以 JSON 形式存档于 `../../micro/` 备查。
2. **词典同源声明**：A 方独立复算沿用同一套自建词典（408/595 词），两方言差仅在增删裁决，裁决清单见附录一 1.3 节。
3. **训练语料条数按实标注**：neg 语料为 18575 条（本研究 venv 环境 snownlp 版本实有条数），与其他环境中可能存在的 18576 条版本相差 1 条，系库版本差异，特此声明。

## 复核路径

- 数值复核：`数据附录数值表.xlsx` 各 sheet 与正文图表（图A–图G、实验流程图）一一对应，对应关系见汇编各节"支撑图X"标注。
- 计算复核：全部原始 JSON 与脚本存于 `../../macro/`、`../../micro/`、`../../lexicons/`、`../../scripts/`。
- 偏置复核：以两个 SnowNLP 训练语料全表对照《铸剑》语料，可复现正文"电商语域高估文学语句正极性"的论证过程。
