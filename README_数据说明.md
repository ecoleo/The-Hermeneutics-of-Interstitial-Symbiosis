- 剔除：页眉（篇名书眉 / “鲁迅全集·故事新编”）、页脚原书页码、注释（〔n〕起至篇末的注文块）

## 各数字人文工具接入方式
- **BERTopic**：用 `故事新编_八篇_结构化.csv` 或 `故事新编_八篇合集.txt` 作为输入语料，按 `title` 归并文档即可进行主题建模；中文建议先分词（jieba）再喂入。
