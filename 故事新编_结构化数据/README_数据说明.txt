================================================================
《故事新编》八篇小说正文 · 结构化语料数据包
================================================================

一、数据来源
----------------------------------------------------------------
源文档：《故事新编》截取版.pdf（147页扫描件，对应《鲁迅全集》
书页351–497，每页为整页扫描图像，无文字层）。
处理流程：RapidOCR 中文识别（300 DPI）→ 依据行坐标精确定位
页眉/页码/注释区 → 剔除冗余 → 按缩进重建段落 → 多格式输出。

二、清洗规则（可复核、可复现）
----------------------------------------------------------------
1. 剔除页眉：页面顶部"鲁迅全集·故事新编"（偶数页）与篇名/
   "序"（奇数页）。
2. 剔除页码：页面底部纯数字行（351–497）。
3. 剔除非正文区：编者题注（p2）、作者序言（p3–4）、各篇注释
   （篇末署名行之后至下一篇扉页，共约40页《鲁迅全集》注释）。
4. 剔除正文内注释标号：[n] {n] 【n} ［n］ (n) 及OCR残缺变体
   （如 [12, 、40) ）。
5. 剔除篇末署名行（"一九X年X月作。"），写作时间移入元数据表。
6. 段落重建：普通各篇按行首缩进（横坐标偏移>45px）判定段落
   起点；《起死》为戏剧体，按"说话人（庄子/汉子/巡士/司命/
   鬼魂）+舞台指示（起始括号）"分段。
7. 分句规则：以 。！？…； 为句末边界，句末后随引号/括号归入
   该句；过滤长度<2的碎片。
8. 全部输出为 UTF-8 编码；CSV 采用 utf-8-sig（带BOM），
   Excel/WPS 直接双击打开不乱码。

三、目录结构与文件说明
----------------------------------------------------------------
1_分篇正文_纯文本/  01_补天.txt … 08_起死.txt
    每篇一个纯文本文件，一段一行。可直接上传 Voyant Tools
    （voyant-tools.org → Open → 上传整个文件夹或多个文件），
    亦适用于 AntConc、ROST CM6 等接受 txt 的工具。

2_全文合并/  故事新编_八篇全文.txt
    八篇合并，以【篇N：篇名】（写作时间）标识分区。
    适合 Voyant 单文档模式下观察篇际词频对比。

3_分句语料/  故事新编_句子级.csv / .jsonl
    字段：sentence_id, story_id, 篇名, para_id, sent_id, sentence。
    推荐用于：情感分析（SnowNLP/cnsenti/大连理工情感词汇本体
    逐句打分）、BERTopic 句子级主题建模。

4_文档级语料/  故事新编_段落级.csv / 故事新编_篇章级.csv
    段落级：BERTopic 建模推荐单位（8篇共927段，兼顾文档量与
    语义完整性）；篇章级：每篇一文档（8篇），适合远读尺度的
    篇际对比（对应"宏观历时"进路）。

5_结构化JSON/  故事新编_结构化数据.json
    完整结构：元数据 + 全文 + 段落数组 + 句子数组，Python
    直接 json.load 即可进入任何分析管线。

6_元数据/  故事新编_篇目元数据.csv
    篇名、原题、写作时间、初刊信息（据本书注释）、书页/PDF页
    码范围、字符数、段落数、句数。

7_参考_非正文/  编者题注.txt、序言.txt
    从语料中剔除的编者题注与鲁迅自序，单独归档备查。
    注意：不纳入任何分析语料。

8_质量控制/  低置信度OCR行清单.txt
    OCR置信度<0.70的原始识别行（含页码与坐标），供人工抽查。

9_分词语料/  故事新编_段落级_分词.csv / 故事新编_句子级_分词.csv / 停用词表.txt
    jieba分词结果，两列关键输出：
    tokens_raw       —— 全部词元（空格分隔，保留标点）；
    tokens_filtered  —— 已去停用词/标点/纯符号/数字，可直接作为
                       BERTopic 的 documents 输入（配合中文向量
                       模型），亦可用于词频统计与共现分析。
    停用词表.txt：通用中文停用词表（goto456/cn_stopwords，746词）
    + 扩展项（标点符号、OCR噪声如"一一/··"），共791词，一行一词。

10_TEI_XML/  故事新编.tei.xml
    TEI P5 标准格式：teiHeader 记录书目与来源信息，每篇一个
    <div type="story">（含 xml:id 与篇目元数据 <note>），段落为
    <p xml:id="storyN-pXXX">。可直接导入支持 TEI 的数字人文平台
    （如 TXM、oXygen、TEI Publisher），亦便于后续添加人名/地名/
    事件标注，衔接"微观增强"阐释进路。

五、使用建议与已知限制
----------------------------------------------------------------
1. OCR误差：本语料为扫描件机器识别结果，存在少量字形误识
   （如"懊恼"误作"噢恼"、"自己"误作"自已"、破折号"——"
   误作"一一"、省略号"……"形态波动、个别句号丢失）。主题
   建模与词频统计对此稳健；若用于逐字引用，请对照原书核校。
   建议先抽查"8_质量控制"清单所列行。
2. 标点说明：引号保留原书样式，逗号存在全角/半角混用（OCR
   所致）。分句已兼容两种；若需统一，可运行
   text.replace(',', '，') 之类规范化（对统计影响极小）。
3. BERTopic 中文注意：可直接使用"9_分词语料"的 tokens_filtered
   列作为文档；向量层建议使用支持中文的多语言
   sentence-transformer 模型（如 paraphrase-multilingual-
   MiniLM-L12-v2）。段落级（927篇文档）为推荐建模单位。
4. Voyant：上传"1_分篇正文"整个文件夹即可获得分篇可比的
   词频、关键词（TF-IDF）、词汇趋势与气泡图；配合元数据中
   的写作时间可做历时观察（对应论文"宏观历时"进路）。
5. 情感分析：句子级CSV已含篇名与段落编号，便于按篇/段聚合
   情感曲线，观察《故事新编》戏拟反讽的语气起伏。
6. 《起死》为戏剧体，舞台指示以圆括号标注、说话人以
   "人名——"标注，段落切分即对话轮次，可直接用于对话网络
   分析（说话人—受话人矩阵）。
